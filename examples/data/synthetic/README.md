# Synthetic data: invented, not real participants

This corpus is generated by [`../make_synthetic.py`](../make_synthetic.py), a seeded standard-library script. Every
conversation, speaker and number in it is invented. No real study, no real people, no real scores.

The `phq9` meta key on each user is an arbitrary integer (0 to 27) assigned by the script. It keeps that name so the
example pipelines read like a real analysis, but it was never produced by a questionnaire and is **not clinically
meaningful**. Do not cite, publish or reuse any of this as findings about people.

It is a ConvoKit corpus (`index.json`, `utterances.jsonl`, `speakers.json`, `conversations.json`, `corpus.json`):
19 conversations, 1,543 utterances, 20 speakers (19 fictional users and one neutral assistant). ckviz uses it as the
`synthetic` dataset, as a fixture for the fast test suite, and in the `phq9-fighting-words` and `dlatk-phq9` examples.

**What is planted.** Each user message may gain a clause about gardening, more likely the higher the score (5% at
score 0, 45% at score 27), and a clause about cycling, less likely the higher the score (45% to 5%). Every gardening
clause contains "compost" and every cycling clause contains "bicycle". Those topics were chosen for having nothing to
do with mood or health. Those two words should come out on top in both examples, and any other word that does is
either part of a planted clause or chance.

**Rebuild** (`tests/test_make_synthetic.py` checks the committed files match byte for byte):

```sh
python examples/data/make_synthetic.py
```
